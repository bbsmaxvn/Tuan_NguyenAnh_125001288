# VALORANT Landing Page — Thiết kế Web

Landing page giới thiệu game theo phong cách chiến thuật/esports, xây dựng bằng HTML5 và CSS3 thuần, không sử dụng JavaScript.

## Cấu trúc

- `index.html` — cấu trúc Semantic HTML5 và nội dung trang.
- `style.css` — CSS Variables, giao diện, responsive, hover/focus, menu mobile CSS-only và hiệu ứng cuộn bằng CSS.
- `PROMPT_LOG.md` — nhật ký Prompt Engineering.

## Thư viện và hiệu ứng

- Animate.css: hiệu ứng mở đầu cho tiêu đề và CTA.
- CSS Scroll-driven Animations: hiệu ứng xuất hiện khi cuộn trên trình duyệt hỗ trợ.
- Google Fonts: Inter và Barlow Condensed.
- Không sử dụng AOS vì AOS cần JavaScript để khởi tạo; hiệu ứng cuộn được thay bằng CSS thuần theo yêu cầu không dùng JS.

## Chạy thử

Mở `index.html` trên trình duyệt. Để dùng GitHub Pages, tải các file lên repository, vào **Settings → Pages**, chọn nhánh `main` và thư mục `/ (root)`, sau đó lưu lại.

## Trước khi nộp bài

1. Đổi tên repository đúng cú pháp giảng viên yêu cầu: `Ten_Ho_MSSV`.
2. Kiểm tra lại họ tên/MSSV trong `PROMPT_LOG.md`.
3. Kiểm tra trang trên điện thoại và máy tính.
4. Thêm link GitHub Pages vào phần About của repository.
5. Ghi lại trung thực quá trình prompt và các chỉnh sửa của bản thân.

Đây là sản phẩm mô phỏng phục vụ học tập, không phải website chính thức của Riot Games. Logo và tên trò chơi thuộc quyền sở hữu của chủ sở hữu tương ứng.
